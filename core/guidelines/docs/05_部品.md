# 05 部品

## 方針

- **土台は Kedama Design System**（`@kedama-design/design-system`。2026-11-05 yuuki 決定。v1.0 の「Sparkle Design を土台にする」から変更）
  - 部品の**見た目（色・書体・余白・角丸・寸法）はこの指針の値に合わせる**。Kedama の既定の見た目は使わない
  - 主ボタンはインク色。アクセント色は設けない
- Sparkle Design は使わない（ライセンス確認も不要になった）

## Kedama から使う部品（Kedama 0.1.2 時点。見た目はこの指針に合わせる）

ボタン／入力欄（TextField）／ダイアログ・モーダル／カード／アイコン／テーマ切替／スケルトン／スピナー／アコーディオン／表（Table）／シート（Drawer）／トースト

（バッジは部品としては使えるが、状態の表示には使わない。状態は `04_状態アイコン.md`）

## 製品側で作る部品（Kedama に無いもの。着手時に Kedama の最新版で有無を確かめる）

テキストエリア／セレクト／チェックボックス／ラジオ／スイッチ／パンくず／ツールチップ／インラインメッセージ／区切り線

## 自作する部品（画面の骨格など）
