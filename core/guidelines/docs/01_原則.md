# 01 原則

1. **注目を集めすぎない**。画面の主役は作業の中身（記事・データ）で、外枠や装飾ではない
2. **色は意味を持つところだけ**。面・文字・枠は白黒（インクと紙）で作り、色は状態アイコンにだけ付ける
3. **強弱は太さと位置で付ける**。目立たせたいものは文字を太くする・上に置く。色や背景で囲まない
4. **色だけに頼らない**。状態アイコンは形でも区別できるようにし、文字のラベルを必ず添える（またはマウスを重ねたとき・読み上げで出す）
5. **作る側の道具として、迷わせない**。よく知られた配置（Codex・Linear 型）を使い、独自の操作を増やさない

## しないこと

- 色付きのタグ（バッジ）で状態を塗り分ける
- グラデーション、影の強いカード、左端に色の線を引いたカード
- 外枠に常設のタブやステータスバーを置く
