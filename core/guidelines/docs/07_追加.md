## ダーク

- 方針：インクと紙を反転する。色を付けるのは状態アイコンだけ。面・文字・線の階調の段数はライトと同じにする
- 状態アイコンの色は意味（灰＝未着手、橙＝社内で進行中、青＝相手の確認待ち、緑＝完了、赤＝異常）を保ったまま、暗い地で見える明るさに上げる
- 記事面（プレビュー・見たまま編集・コメントの印）は、ダークでも白地（WordPress 上の見え方を確かめるため）
- 切替：OS の設定に従う（既定）／ライト／ダーク。OS 追従はスクリプトで `<html data-theme>` を付ける方式にし、CSS の `prefers-color-scheme` で色を分けない
- **色の値は未決**。yuuki が色見本で確認してから `tokens/tokens.json` に追記する

## 画面の幅（スマホ・タブレット）

| 幅 | AppShell |
|---|---|
| 1200px〜 | `02_AppShell.md` の5領域そのまま |
| 768〜1199px | ②アプリ切替の列は表示。③サイドバーは開閉式。⑤右パネルは本文に重ねて表示 |
| 〜767px | ②と③を左からの引き出しにまとめる。クライアント切替は引き出しの先頭。⑤右パネルは下からのシート |

- どの幅でも、外枠にタブとステータスバーは置かない
- 一覧の表は、スマホではカード（タイトル・状態アイコン・更新日。クライアントは「すべてのクライアント」を選んでいるときだけ）
- 画面内タブは、スマホでは横スクロール
