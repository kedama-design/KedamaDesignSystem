## 4. DERIVED 表（ガイドラインに無い値・解釈した値）

正は `test/helpers.mjs` の `DERIVED`。この表はその写しで、`test/tokens.test.mjs` が名前の一致を確かめる。

| 名前                         | 種類                               | 値                              | 理由・決め方                                                                                                                                       |
| ---------------------------- | ---------------------------------- | ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--ui-scrim`                 | ガイドラインに無い値（決め方つき） | `rgba(38,37,31,0.10)`           | ドロワー・小窓の後ろの覆い。インク色（`--ui-text-high` の RGB）の 10%。ガイドラインに覆いの色の定めが無い。RGB と不透明度 10% の両方をテストで照合 |
| `--ui-action-primary-hover`  | 決め方で作る値                     | `#403f3a`                       | インク色 `#26251f` を白へ 12%: 各成分 `c + (255 − c) × 0.12`                                                                                       |
| `--ui-action-primary-active` | 決め方で作る値                     | `#1d1c17`                       | インク色を黒へ 25%: 各成分 `c × 0.75`                                                                                                              |
| `--ui-control-h-md`          | 解釈                               | `36px`                          | tokens.json「32〜36px」から 36px を選んだ                                                                                                          |
| `--ui-row-h`                 | 解釈                               | `44px`                          | tokens.json「約44px」                                                                                                                              |
| `--ui-rail-item`             | 解釈                               | `40px`                          | tokens.json「40px（角丸10px）」の大きさ（角丸は `--ui-radius-lg`）                                                                                 |
| `--ui-space-N`               | 名前の付け方                       | `--ui-space-1`〜`--ui-space-12` | tokens.json の `space.values` に名前が無いので `--ui-space-{px ÷ 4}`                                                                               |

hover・active の決め方の細部: sRGB 8bit の各成分で計算し、端数は `Math.round`（**0.5 は切り上げ**）。active の赤の成分は 38 × 0.75 = 28.5 → 29（`1d`）。偶数への丸めにすると `#1c1c17` になる。

tokens.json の値の葉はすべて、`test/helpers.mjs` の `jsonChecks` で JSON から直接読んで `ui/tokens.css` と照合する（色・書体・文字の大きさと太さ・余白・角丸・外枠の寸法・影）。照合しない葉は `JSON_LEAVES_ELSEWHERE` に理由つきで載せ（`layout.controlHeight.md` は範囲の検査、`space.scale` は 4 の倍数の検査）、どちらにも無い葉が tokens.json に増えるとテストが落ちる。名前の付け方はこちらで決めたもの: `--ui-font-size-*`・`--ui-font-weight-*`・`--ui-radius-*`・`--ui-action-secondary`／`-secondary-border`／`-on-secondary`・`--ui-border-input`・`--ui-topbar-h`・`--ui-rail-w`・`--ui-sidebar-w`・`--ui-panel-w`・`--ui-page-pad-x`・`--ui-tab-h`・`--ui-control-h-sm`。
